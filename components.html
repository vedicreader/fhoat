components

Oat’s components as FastHTML functions, with the same names as fasthtml.pico where Pico has one.

Plain tags need no helper: Button, A, Input, Select, Textarea, Table, Dialog, Details, Progress, Meter and the headings are styled as they are. A Div has no look of its own; give it a class (card, row, hstack, vstack, container) or use the functions below. An accordion is plain Details(Summary('Title'), P('Body')).
